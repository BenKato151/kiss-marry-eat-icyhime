# Custom Kiss-Marry-Kill
An easily customizable kiss-marry-kill (or rather here: eat) page template made in html, css and javascript with downloadable results in CSV for the german VTuber [Icyhime](https://www.twitch.tv/icyhime).

## How to use / download
You can use my template using one of this methods available:
- Fork my Repository -__Recommended__-
- Download my repository as a zip file

⬇️ Use the following guide for editing the template ⬇️

## Editing Language / Texts
The page is in German by default, but you can modify the text in the HTML/JavaScript files

Look for the texts showed in the images below when editing the files and change it to whatever you want

Then you can host your page with github pages or other hosting methods (Or run it locally on your machine)

## Editing Characters
In the JavaScript file named "characters.js" you can find the characters list, you can modify it to your likings.
Basically, the scheme is as follows: `{name: "character-name", images: ["kiss_marry_eat/character-name/image-1.png", "kiss_marry_eat/character-name/image-2.jpg"]}`
